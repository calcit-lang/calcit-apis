# Calcit project reference

This repository uses the canonical `calcit.cirru` snapshot and current Calcit CLI.

Query maintained guidance when needed:

```bash
calcit docs agents --full
calcit docs read upgrade --full
calcit docs read edit-tree.md --full
calcit docs read static-analysis.md --full
```

Use `calcit` for query, editing, checking, and code generation. Do not use `cr` or document the retired `compact.cirru` workflow here.
